# Chronicle.Plugin.Steam

Metadata provider plugin for **Steam**.

## Design Document

Full design documentation:
[docs/plugins/PLUGIN_STEAM.md](https://github.com/thegoddamnbeckster/Chronicle/blob/develop/docs/plugins/PLUGIN_STEAM.md)

## Supported Media Types

`game`

## Quick Start

1. `dotnet build`
2. Copy `Chronicle.Plugin.Steam.dll` to your Chronicle `plugins/active/` directory
3. Restart Chronicle
4. Navigate to **Settings -> Plugins -> Steam**
5. Configure required settings (see design doc)
